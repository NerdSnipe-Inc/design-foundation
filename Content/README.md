# Screenshot Catalog

Generated by `scripts/generate_screenshot_catalog.py`. Do not hand-edit anything
under this folder except this README — everything else is regenerated.

Run it from the repo root:

```bash
python3 scripts/generate_screenshot_catalog.py
```

This drives the real desktop for ~15-20 minutes (it launches DFPlayground once per
catalog entry, brings it frontmost, screenshots its window, and closes it) — run it
only when you're at the machine and not relying on other foreground windows during
that window. See the script's module docstring for details, and
`docs/superpowers/plans/2026-09-07-wave2-screenshot-pipeline.md` for how it's wired
together.

To iterate on the framing/index style without re-driving the GUI every time, reuse
already-captured raw screenshots:

```bash
python3 scripts/generate_screenshot_catalog.py --skip-capture
```

- `RawCaptures/` — raw, unframed window screenshots (gitignored; regenerate anytime)
- `Frames/` — each raw capture composited onto a themed card (`*.framed.png`)
- `Groups/` — per-category strip composites of the framed shots (`*.strip.png`)
- `index.md` — the master catalog page, grouped by category

Pro-tier entries (Pro Screens, Pro Blocks, Shell Layouts, Composition Examples) also
write a mirrored `Frames/`, `Groups/`, and `index.md` into
`../DesignFoundationPro/Content/`, cross-linked from this folder's `index.md`.
